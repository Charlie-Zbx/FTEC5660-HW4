# Task 6: Reflection

This homework made the idea of working with a capable AI agent feel more practical to me. Even if AI becomes much stronger in ten years, I would still want to understand the work I submit. In this project, getting a running program was only part of the task. It was also necessary to check whether the retrieved passages belonged to the right company and year. I would want to be someone who asks these questions instead of accepting an answer just because it looks reasonable.

My current goal of becoming better at programming and solving problems would still matter. For this homework, that means understanding how a table becomes text, how documents are split, and how evidence is selected. I do not need to memorise every line of code, but I want to be able to explain the main choices and find where a wrong answer comes from.

Beyond finishing work quickly or getting a good grade, I would like to be known as reliable and honest. In a project like this, that means reporting results as they are, including changes that did not help. It also means making the instructions clear enough for another person to run the project and being open about what has not been tested.

I would still be willing to spend time understanding mistakes, even when AI could suggest a quick fix. A financial number can be copied correctly but still answer the wrong question if its year or column heading is missing. A comparison also needs evidence for both companies. Working through these details is sometimes tedious, but it helps me understand the problem better than simply accepting a patch.

Patience, careful reading, and clear communication would remain useful skills. The ablation study showed that a change that sounds sensible does not always improve the result. I want to get better at testing one change at a time, checking the evidence, and explaining what the results actually support. These habits would also help when working with other people.

I would not want to define myself only by a test score or the amount of code I produce. Passing the public questions is encouraging, but it does not prove that the system will handle unfamiliar companies or different wording. I would care more about whether I understand the limitations, learn from mistakes, and take responsibility for the work I hand in.

For my next project, I would start by writing down the requirements and a few small test cases. When using AI, I would ask for an explanation of a proposed change and check it against the source material. Before submitting, I would run the project from a clean setup and read the final report myself. These are manageable steps that would help me use AI while continuing to learn.
